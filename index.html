LinkPanels AI

개인정보처리방침

시행일: 2026년 11월 12일 · 적용 버전: 0.3.12 이상

LinkPanels AI(이하 "확장")는 Chrome 새 탭을 개인 링크 보드로 바꾸는 브라우저 확장입니다. 이 방침은 확장이 어떤 정보를 다루고, 어디에 저장하며, 언제 누구에게 보내는지 설명합니다.

1. 요약

  • 개발자는 서버를 운영하지 않으며, 사용자의 보드나 API 키를 받거나 보관하지 않습니다.
  • 보드와 설정은 사용자의 Chrome 프로필 안에 저장됩니다. 사용자가 동기화를 켜면 Chrome 동기화를 통해 사용자의 Google 계정에도 저장됩니다.
  • 사용자가 AI 기능에서 요청 버튼을 누를 때만, 선택한 범위의 링크 정보가 사용자가 고른 AI 제공사로 직접 전송됩니다.
  • 광고, 분석, 추적 도구를 쓰지 않으며 정보를 판매하지 않습니다.

2. 확장이 다루는 정보와 저장 위치

정보용도저장 위치
링크 보드 (작업 공간·그룹 이름, 링크 제목·주소·태그, 즐겨찾기, 화면 설정)새 탭에 보드 표시이 기기의 확장 저장 공간(chrome.storage.local). 사용자가 동기화를 켠 경우에만 아래 동기화 사본을 만듦
AI 연결 정보 (제공사, 모델 ID, API 키)사용자가 고른 AI 제공사 인증사용자가 고른 방식에 따라 이 기기의 확장 저장 공간(local) 또는 브라우저 종료 시 지워지는 세션 저장 공간(session). 보드 백업 파일에는 포함하지 않음
모델 목록 캐시모델 선택 화면 표시세션 저장 공간, 최대 24시간
열린 탭·최근 닫은 탭 목록 (제목·주소)'탭 모아보기' 화면 표시, 사용자가 고른 탭 저장·이동·복원저장하지 않음. 사용자가 보드에 저장한 탭만 보드에 남음
Chrome 북마크 (폴더 이름, 북마크 식별자·제목·주소·추가 시각)사용자가 'Chrome 북마크 가져오기'를 누를 때 보드로 가져오기. 0.3.12부터는 보드를 열 때 최근 추가한 북마크 최대 20개를 읽어 상단에 표시하고, 보드가 열려 있는 동안 변경을 반영최근 목록 자체는 따로 저장하거나 동기화하지 않음. 사용자가 가져오거나 그룹에 담은 링크만 보드에 저장. Chrome 원본 북마크는 변경하거나 삭제하지 않음
자주 방문한 사이트 목록 (제목·주소, 최대 20개)사용자가 '자주 가는 사이트'를 누를 때 고른 사이트를 보드에 담기목록은 저장하지 않음. 사용자가 고른 사이트만 보드에 남음
사이트 파비콘보드·빠른 접근·탭 목록에서 사이트 구별Chrome 내부 파비콘 경로를 사용합니다. 별도 외부 아이콘 서비스로 링크를 전송하지 않습니다.
동기화 사본 (링크 보드 전체를 압축한 사본)사용자가 '다른 기기와 동기화'를 켠 경우 같은 Google 계정의 다른 Chrome과 보드 맞추기Chrome 동기화(chrome.storage.sync)를 통해 사용자의 Google 계정에 저장. 개발자는 이 사본에 접근할 수 없음. API 키는 포함하지 않음

API 키는 별도 암호화 금고에 보관되지 않습니다. 이 Chrome 프로필에 접근할 수 있는 사람은 저장된 키에 접근할 수 있으니, 공용 기기에서는 'Chrome 종료 시 삭제'를 선택하세요.

3. 외부로 전송하는 정보

확장이 외부와 통신하는 곳은 사용자가 연결한 AI 제공사 한 곳뿐입니다. 확장 보안 정책(CSP)이 다른 주소로의 연결을 막습니다.

모델 목록 조회: 인증을 위해 API 키만 보냅니다.

AI 요청 (사용자가 요청 버튼을 누를 때만):

  • 보내는 것: 선택한 범위(현재 보드 전체 또는 그룹 하나)의 작업 공간·그룹 이름과 식별자, 그룹의 배치·고정·접힘 상태, 링크 식별자·제목·전체 주소·태그, 사용자가 입력한 요청 문장
  • 0.3.10부터 저장 링크의 전체 주소를 보냅니다. 쿼리 문자열(? 뒤), # 뒤 부분과 경로의 문서 ID를 포함하므로 검색어, 필터, 문서·영상 식별자 또는 공유 토큰이 전달될 수 있습니다. 사용자 이름·비밀번호가 주소에 포함된 링크와 HTTP(S)가 아닌 링크는 제외합니다.
  • 보내지 않는 것: 웹 페이지 본문, 방문 기록, 열린 탭 목록, 최근 북마크 목록 자체, 선택하지 않은 작업 공간. AI가 링크 주소로 페이지를 직접 열거나 본문을 읽는 기능은 제공하지 않습니다.
  • 새 탭을 열 때 자동으로 요청하지 않으며, 실패해도 자동으로 다시 시도하지 않습니다.

AI는 저장된 제목·주소·태그를 근거로 정리와 링크 이름 변경을 제안합니다. 이름 변경 전후를 확인하고 사용자가 선택한 변경만 보드에 적용합니다. 링크 주소 자체는 바꾸지 않습니다.

0.3.9 이하에서는 저장 링크 주소의 쿼리 문자열과 # 뒤 부분을 제외합니다. 사용자가 요청 문장에 직접 넣은 주소나 내용은 버전과 관계없이 그대로 전달됩니다.

전송된 정보는 해당 AI 제공사의 약관과 개인정보처리방침에 따라 처리됩니다. API 사용료도 제공사 계정에 청구됩니다.

  • OpenAI 개인정보처리방침
  • Google 개인정보처리방침 (Gemini API)
  • Anthropic 개인정보처리방침

4. 권한

0.3.7부터 보드와 브라우저 기능 권한은 Chrome 설치 승인 화면에서 함께 요청합니다. 기존 버전에서 업데이트할 때에는 새 권한에 대한 재승인이 필요할 수 있습니다.

  • storage: 보드, 설정, API 키를 이 기기에 저장합니다.
  • tabs, sessions: 사용자가 '탭 모아보기'를 열 때 열린 탭과 최근 닫은 탭을 표시하고, 선택한 탭의 이동·저장·복원을 수행합니다.
  • bookmarks: 사용자가 'Chrome 북마크 가져오기'를 누를 때 북마크를 읽습니다. 0.3.12부터 보드를 열 때 최근 추가한 북마크 최대 20개의 제목·주소 등 목록 표시와 갱신에 필요한 정보를 읽고, 보드가 열려 있는 동안 북마크 변경을 반영합니다. 이미 LinkPanels에 저장된 주소는 최근 목록에서 숨깁니다. Chrome 원본 북마크는 변경하거나 삭제하지 않으며, 이 기능은 방문 기록이나 페이지 본문을 읽지 않습니다.
  • topSites: 사용자가 '자주 가는 사이트'를 누를 때 Chrome이 집계한 사이트 목록을 읽습니다. 전체 방문 기록은 읽지 않고 외부로 보내지 않습니다.
  • favicon: 보드와 탭 목록에 Chrome이 제공하는 사이트 아이콘을 표시합니다. 별도 외부 파비콘 서비스는 사용하지 않습니다.
  • AI 제공사 주소 접근 (선택): AI 연결에서 사용자가 고른 제공사 한 곳에 대해서만 요청합니다.

설치 권한 승인만으로 탭이나 북마크를 자동으로 보드에 저장하거나 AI에 보내지 않습니다. 최근 북마크 목록 자체는 별도로 저장·동기화하지 않고 AI 제공사에도 보내지 않습니다. 사용자가 최근 목록의 링크를 그룹으로 드래그하거나 그룹을 선택해 담으면 일반 보드 링크로 저장됩니다. 보드 동기화를 켠 경우 해당 저장 링크는 다른 기기와 동기화되며, 이후 사용자가 실행한 AI 요청의 선택 범위에 포함한 경우에만 위 AI 전송 정책에 따라 링크 제목·전체 주소 등 선택 범위의 정보가 선택한 AI 제공사로 전송됩니다.

Recently added bookmarks (0.3.12+): When you open a board, LinkPanels reads up to 20 recently added Chrome bookmarks and refreshes the list while the board is open. URLs already saved in LinkPanels are hidden. The recent list itself is not stored, synced, or sent to AI providers. Copying a link into a group saves it as a regular board link, subject to optional board sync and later AI requests you explicitly run with that link in the selected scope. Original Chrome bookmarks are never modified or deleted. This feature does not read browsing history or page content.

0.3.6 이하에서는 tabs, sessions, bookmarks, topSites를 각 기능을 사용할 때 선택 권한으로 요청합니다.

5. 정보 삭제

  • API 키: AI 도우미 › AI 연결 › '연결 해제 · 저장한 키 삭제'. 제공사에서 발급한 원본 키는 제공사 사이트에서 따로 폐기해야 합니다.
  • 보드: 보드에서 직접 지우거나, 확장을 삭제하면 확장 저장 공간 전체가 지워집니다. 필요하면 삭제 전에 JSON으로 백업하세요.
  • 개발자는 사용자 정보를 보관하지 않으므로, 개발자에게 삭제를 요청할 정보가 없습니다. 이미 AI 제공사로 전송된 정보는 해당 제공사에 문의해야 합니다.

6. 아동

이 확장은 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 변경

방침이 바뀌면 이 페이지의 시행일을 고치고, 전송 정보나 목적이 달라지는 경우 확장 업데이트 안내에 함께 알립니다. 유료 이용권이 추가되면 결제와 계정 정보 처리를 이 방침에 추가합니다.
